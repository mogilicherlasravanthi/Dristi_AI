# Dristi AI

**SIH Problem Statement:** SIH26038 — Explainable AI for Diabetic Retinopathy Screening in Rural India

Dristi AI provides an explainable AI solution for accessible and reliable diabetic retinopathy screening tailored for rural healthcare settings in India.
